# PHOENIX — Domain Context Reference

## LotusBook Scraping

### Page Structure
- URL: `https://lotusbook.cc/cricket`
- **"In Play" section** at top → live matches
- **"Upcoming Events" section** below → scheduled matches
- 1X2 odds grid per match: Column 1 (Home), X (Draw), 2 (Away)
- Each column: Back price | Lay price
- Competition badges (ICC T20 World Cup, WPL, IPL, BBL, etc.)

### DOM Extraction (worker.py)
JavaScript runs inside Playwright to extract matches. Key logic:
- Walk up DOM from each match link to find section header
- If header contains "Upcoming" → `is_live = false`
- If time text matches date pattern (DD/MM/YYYY, "Tomorrow", "Today") → `is_live = false`
- Only trust live indicators when NOT in upcoming section
- Score patterns like "45/2" confirm live status

### Match ID Format
Generated by parser as `lb_` + hash of home+away+competition. Deterministic — same teams in same competition always produce same ID.

### Odds Validation
- Odds must be > 1.0 (decimal format)
- Back ≤ Lay (no reverse spread)
- Back-Lay spread < 50% of back price (reject extreme spreads)
- Null odds are allowed (partial data) but filtered to None by parser

**Key Tactical Rules:**
- In Women's matches, top-order wickets cause sharper momentum shifts because tail batting depth is shallower.
- Lay liability must NEVER exceed 2.10 decimal odds (`lay_odds <= 2.10`).
- Greening Up: When odds on an open exposure compress below 1.80 with win probability > 60%, the agent lays the position to lock in guaranteed risk-free profit.

- **Exchange Commission:** 2.0% deducted from net winning trades.
- **Hedging Rate:** At least 35–40% of positions hedged (two-way trades covering both outcomes).

- Win rate > 55%
- ROI > 8%
- Sharpe ratio > 1.5
- Max drawdown < 15%
- 10+ profitable days in last 14
- 100+ bets in last 30 days

## Betting Math

### BACK Bet
- **Win**: profit = stake × (odds - 1) × (1 - commission)
- **Loss**: profit = -stake

### LAY Bet (you act as the exchange layer)
- **Win** (selection loses): profit = stake × (1 - commission)
- **Loss** (selection wins): profit = -stake × (odds - 1)
- **Liability**: stake × (odds - 1) — restricted to odds $\le 2.10$

### CLV (Closing Line Value)
Measures edge vs closing market: `CLV = (closing_odds / entry_odds) - 1`
Positive CLV confirms institutional value beat the market before closing.
